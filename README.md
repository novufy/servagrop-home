# Servagrop · Home (prototipo)

Sitio estático: `index.html` + carpeta `img/`. No requiere build.

- Tipografía: DM Sans (Google Fonts, por link).
- Animaciones: GSAP 3.13 + ScrollTrigger + SplitText (por CDN jsDelivr).
- Menú sin enlaces a páginas internas (pendientes).

## Publicar en Vercel
1. Subir el contenido de esta carpeta (index.html, img/, README.md) a un repo de GitHub.
2. En Vercel: Add New → Project → importar el repo.
3. Framework Preset: Other. Sin Build Command ni Output Directory. Deploy.
